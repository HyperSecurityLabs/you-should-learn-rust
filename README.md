## 🚀 How to Use

Each `.rs` file compiles standalone with `rustc`:

```bash
# Beginner
rustc beginner/01_hello.rs && ./01_hello

# For the full tutorial experience
rustc intro_to_rust.rs && ./intro_to_rust
```

> All files use `rustc` (no `cargo` needed).  
> Offensive networking files require `libpnet` — run with `cargo` or adjust your library path.

---

## 🧠 Teaching Style

Every file is written in the **Rust girlfriend persona** — long `//` comments that explain everything like your lover whispering in your ear. Advanced files include playful  metaphors for unsafe concepts. Offensive files include ethical warnings.

> "Don't be scared, baby. I'd never hurt you. I'm just showing you how the bad men play."
